# HA Views

HA Views is a visual Home Assistant entity dashboard editor.

## Instalacja i uruchomienie

Po zainstalowaniu uruchom dodatek, otwórz jego interfejs i:

1. włącz tryb edycji;
2. wgraj obraz tła;
3. w zakładce **Integracje** dodaj encje;
4. ustaw markery Badge lub Gauge na widoku;
5. dopasuj ich wygląd.

## Installation and setup

After installation, start the add-on, open its web interface and:

1. enable edit mode;
2. upload a background image;
3. add entities from **Integrations**;
4. position Badge or Gauge markers;
5. customize their appearance.

> Beta software — create a Home Assistant backup before updating.
