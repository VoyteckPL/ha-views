# HA Views

![HA Views](logo.png)

Twórz własne wizualne pulpity Home Assistanta na dowolnym obrazie tła.

HA Views pozwala rozmieszczać encje jako konfigurowalne markery **Badge** i **Gauge**. Stany aktualizują się na żywo, a jeden układ skaluje się proporcjonalnie na komputerze, laptopie i telefonie.

## Najważniejsze funkcje

- własne tła PNG, JPG i WebP;
- przeciąganie i skalowanie markerów;
- Badge i Gauge z pełną konfiguracją wyglądu;
- ikony encji oraz dowolne ikony MDI;
- siatka i snap-to-grid;
- kopiowanie i wklejanie stylów 1:1;
- zaokrąglenie wartości i własne jednostki;
- responsywny widok oraz zoom na urządzeniach mobilnych;
- trwały zapis układu i ustawień;
- przeglądarka integracji i encji Home Assistanta.

> Wersja beta. Przed aktualizacją zalecany jest backup Home Assistanta.

---

# English

Create visual Home Assistant dashboards on any background image.

HA Views lets you place entities as fully configurable **Badge** and **Gauge** markers. Entity states update live, while a single layout scales proportionally across desktop, laptop and mobile screens.

## Main features

- custom PNG, JPG and WebP backgrounds;
- draggable and resizable markers;
- fully configurable Badge and Gauge styles;
- entity icons and arbitrary MDI icons;
- grid and snap-to-grid;
- complete 1:1 style copy and paste;
- value rounding and custom units;
- responsive layout and mobile zoom;
- persistent layout and settings;
- Home Assistant integration and entity browser.

> Beta software. Create a Home Assistant backup before updating.
